# Маркетинг и продвижение ProDisser

Рабочая папка развития сервиса: рекламная стратегия, исследования рынка,
настройки кампаний и отчёты по ним. Код сайта отсюда не меняется; правки
страниц, нужные рекламе, оформляются по `CONTRIBUTING.md` отдельными
решениями в `docs/DECISIONS.md`.

Исходная задача — Э11 «Реклама в Яндекс Директе» в `docs/PLAN.md`;
решение об открытии папки и параметрах первого цикла — Р-548.

## Состав

| Каталог | Что лежит | Кто пишет |
|---|---|---|
| `briefs/` | постановки задач (промты) для исполнителя | владелец, исполнитель по согласованию |
| `research/` | экономика, конкуренты, площадки, семантика | исполнитель |
| `strategy/` | варианты стратегий, стратегический план, план теста | исполнитель, выбор — владелец |
| `campaigns/` | настройки кампаний к загрузке: фразы, минус-слова, объявления | исполнитель после выбора варианта |
| `mcp/` | спецификация агента управления рекламой | исполнитель |
| `reports/` | еженедельные отчёты теста | исполнитель или агент |

## Реестр и кабинет руководителя

`registry.json` — машиночитаемый реестр: кампании с бюджетами и
показателями, недельные данные, ключевые выводы, предложения, работы,
сервисы и MCP, перечень документов. Из него и из документов папки
собирается вкладка «Реклама» кабинета руководителя (Р-550):

```
node tools/ads-registry.mjs      # из корня репозитория, после каждой правки
```

Скрипт проверяет реестр (состояния, даты, ссылки на документы) и
отказывает с причиной. Изменения видны в кабинете после выкладки.

Раздел и материалы папки приняты владельцем 12.10.2026 (Р-566), точка
отката — ветка `accepted/ads-2026-10-12`. Обновление данных реестра по
ходу теста — ведение кампаний, а не изменение принятого; состав вкладок,
плиток и правила вывода меняются отдельным решением.

## Порядок работы

1. Постановка в `briefs/` — что тестируем, бюджет, сроки, площадки.
2. Исследования в `research/` — каждое число с источником или с пометкой
   «оценка» и допущениями.
3. Варианты в `strategy/` — владелец выбирает вариант и фиксирует выбор
   решением.
4. Настройки в `campaigns/` — загружаются в кабинет площадки после
   подтверждения владельца.
5. Отчёт раз в неделю в `reports/`: расход, клики, заявки, цена заявки,
   квалификация заявок, решение по порогам остановки.

## Правила

- **Закон.** Пункт 10 ст. 7 Федерального закона «О рекламе» запрещает
  рекламу услуг по подготовке и написанию ВКР, диссертаций и иных
  аттестационных работ. Реклама описывает экспертизу и сопровождение —
  ту же модель, что и сайт.
- **Тон.** Правила `design/HANDOFF.md`, раздел «Правила, которые нельзя
  нарушать»: без «напишем», «под ключ», «гарантия защиты», превосходных
  степеней, эмодзи и обещаний решения кафедры, диссовета, редакции, фонда.
- **Данные.** Выдуманных чисел нет. Нет доступа к данным — запрос владельцу.
- **Деньги.** Запуск кампании и любое изменение расхода — только по явному
  подтверждению владельца, в том числе когда кампаниями управляет агент.
- **Персональные данные.** Рекламное согласие с сайта снято (Р-495); метка
  кампании с заявкой не хранится до новой редакции согласия (Р-496).
  Рассылки и лид-формы со сбором данных — только отдельным решением.
