# Настройки кампаний

| Файл | Что это | Состояние |
|---|---|---|
| `direct.json` | обе кампании Директа одним источником: группы, фразы, комбинаторные объявления, быстрые ссылки, уточнения, минус-слова | проверяется `node --test "marketing/**/*.test.mjs"` и в CI |
| `export/` | файлы загрузки из `direct.json`: таблица на кампанию, минус-слова, все тексты | собираются `node marketing/tools/direct-export.mjs`; руками не правятся |
| `direct-студенты.md` | кампания Директа «Студентам», вариант C | готова к загрузке после подтверждения владельца |
| `direct-аспиранты.md` | кампания Директа «Аспирантам», варианты A и B | готова к загрузке после подтверждения владельца |
| `avito-студенты.md` | объявление Авито для нового аккаунта | ждёт ответа поддержки Авито о блокировке |
| `регламент-заявок.md` | обработка заявок на время теста | к введению с 27.10.2026 |
| `wordstat-маски.csv` | фразы для выгрузки частотности владельцем | ждёт выгрузки |

Правка текста объявления — в `direct.json` и в описании кампании, затем
`node marketing/tools/direct-export.mjs`: проверка не даст источнику,
описанию и файлам загрузки разойтись.

Порядок загрузки — `../launch/05-аккаунт-и-загрузка-директа.md`: кампании
с параметрами и минус-словами — вручную, группы и объявления — из файла,
затем модерация. После модерации — запуск только по подтверждению
владельца.
