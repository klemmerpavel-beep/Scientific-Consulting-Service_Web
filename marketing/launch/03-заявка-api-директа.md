# Заявка на доступ к API Директа и токен Метрики

Срок: **21.10.2026**, сразу после того, как в аккаунте появится первая
кампания (`05-аккаунт-и-загрузка-директа.md`, шаг 4). Рассмотрение — от
часа до 3 рабочих дней, в пик до 7 (`../research/07-директ-загрузка-и-api.md`,
раздел 3). Зачем — предложение p-002: отчёты собирает MCP-сервер
(`../mcp/server/`, Р-569).

Все шаги — под **рабочей учётной записью компании**, той же, на которой
открыт аккаунт Директа: приложения и токены остаются у владельца
учётной записи.

## 1. Приложение для Директа

1. Яндекс ID — «Мои приложения» — «Создать приложение».
2. Название: `ProDisser — отчёты Директа`.
3. Тип: «Для доступа к API или отладки».
4. Права: «Яндекс Директ» — `direct:api`. Других не отмечать.
5. Почта для связи — рабочая.
6. Сохранить. Скопировать **ClientID**; Client secret никому не
   пересылать и в переписку не вставлять.

## 2. Приложение для Метрики

Отдельное приложение: токен Метрики только на чтение, без прав Директа
(спецификация MCP, раздел 5).

1. Название: `ProDisser — статистика Метрики`.
2. Тип: «Для доступа к API или отладки».
3. Права: «Яндекс Метрика» — «Получение статистики, чтение параметров
   своих и доверенных счётчиков» (`metrika:read`). Больше ничего.

## 3. Заявка в Директе

1. Директ — «Настройки API» — принять пользовательское соглашение.
2. «Мои заявки» — «Новая заявка». ClientID — из пункта 1, почта — рабочая.
3. Вид доступа — **тестовый**: он одобряется быстрее и сразу даёт
   Песочницу. В полный переводится той же заявкой.
4. Описание и технические сведения — текст ниже, без правок.
5. После одобрения тестового доступа — «Мои заявки» — перевести в полный.

### Описание приложения

> Приложение ООО «РУСДРОН» (ИНН 9723254250) для работы с собственным
> рекламным аккаунтом без агентства. Назначение — еженедельные отчёты о
> показах, кликах, расходе и конверсиях двух поисковых кампаний и
> подготовка предложений по минус-словам и ставкам. Изменения в кампаниях
> выполняются только после подтверждения владельца аккаунта: приложение
> формирует предложение, владелец получает код подтверждения вне
> приложения. Удаление объектов, финансовые операции и изменение данных
> маркировки приложение не выполняет. Приложение запускается вручную
> сотрудником компании, доступ третьим лицам не предоставляется.

### Технические сведения о приложении

> **Сервисы и методы.** Reports (отчёты CUSTOM_REPORT,
> CAMPAIGN_PERFORMANCE_REPORT, SEARCH_QUERY_PERFORMANCE_REPORT, формат TSV,
> без НДС); Campaigns.get, Keywords.get. Изменения — только после
> подтверждения владельца: Campaigns.update (минус-слова, дневной бюджет),
> KeywordBids.set, Campaigns.suspend и resume, Keywords.suspend и resume.
>
> **Порядок и частота.** Один раз в неделю, в понедельник утром: три-четыре
> отчёта за прошедшую неделю и один вызов Campaigns.get; по запросу
> сотрудника — те же отчёты за другой период, не чаще нескольких раз в
> день. Изменения — единичные вызовы после подтверждения, не больше
> нескольких в неделю. Такая частота следует из недельного цикла
> отчётности: данные нужны раз в неделю, чаще смотреть нечего при бюджете
> около 2 000 ₽ в неделю на кампанию.
>
> **Ограничения и ошибки.** Отчёты запрашиваются в режиме auto; ответы 201
> и 202 обрабатываются повтором того же запроса через интервал из
> заголовка retryIn, общее ожидание ограничено; ReportName уникален для
> каждого определения отчёта. Остаток баллов читается из заголовка Units
> и записывается в журнал. Ошибки API (код, текст, подробности)
> возвращаются сотруднику без повторов; повтор только для очереди отчётов.
> Запросы идут последовательно, без параллельных соединений.

## 4. Токены

Токен получают под той же учётной записью:

```
https://oauth.yandex.ru/authorize?response_type=token&client_id=<ClientID>
```

Токен — длинная строка; срок жизни показан на странице. **Не
пересылать в мессенджерах и почте.** Он вписывается в окружение
MCP-сервера на машине, где тот запускается (`../mcp/server/README.md`,
«Подключение»): владелец вписывает сам или передаёт при встрече.

## 5. Что прислать мне

- ClientID обоих приложений — это не секрет.
- Сообщение «тестовый доступ одобрен» или «полный доступ одобрен» с датой.
- Если заявку отклонили — текст причины из «Моих заявок».
