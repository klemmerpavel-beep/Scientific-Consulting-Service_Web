# Свод решений

Девяносто семь решений, принятых по проекту с августа по сентябрь 2026
года, сведённые к существу. Полный журнал с разбором каждого решения — во
внутреннем репозитории; здесь остаётся то, что нужно знать человеку,
продолжающему работу над кодом.

Формат ссылки на решение по всему проекту — `Р-NN`.

---

## Приём заявок и персональные данные

| № | Решение |
|---|---|
| Р-04 | Заявка сначала сохраняется в базу, потом доставляется. Запись без доставки — задержка ответа; доставка без записи — потерянный клиент и отсутствующий журнал согласия |
| Р-30 | Адрес заявителя берётся из `X-Real-IP`, а не из `X-Forwarded-For`: первый элемент второго задаёт сам отправитель |
| Р-31 | Политика содержимого и сроки доставки: восемь секунд на канал, отказ канала не роняет приём |
| Р-40 | Форма показывает, что отправка идёт, и объявляет результат голосом программы чтения с экрана |
| Р-41 | Правовые тексты не описывают того, чего сайт не делает |
| Р-42 | У каждого правового документа есть дата редакции |
| Р-10 | Отметка согласия на рекламные сообщения — открытый вопрос к юристу. Колонка в базе и поле в схеме разбора есть, видимой отметки в формах нет |

Состав полей форм приведён к направлениям решением Р-96 — один раз и до
открытия сайта. С этого момента состав, порядок, валидация, тексты галочек
согласия и версия текста согласия заморожены: на них завязан журнал согласий
по 152-ФЗ, и изменение состава полей после появления настоящих заявок
разрывает журнал.

## Правила, действующие постоянно

1. Правится макет `design/*.dc.html`, а не сгенерированный компонент.
   Компоненты перезаписываются при каждом переносе, CI проверяет
   воспроизводимость.
2. Каждое решение записывается с разбором, а не только с результатом: через
   полгода важно, почему сделано так.
3. Принятое состояние закрепляется веткой `accepted/…` — точкой отката,
   которую не двигают и не удаляют.
4. Бэкенд не меняется правками вида: схема, миграции, `app/src/app/api/` и
   `app/src/lib/` — только отдельным решением с явной причиной.
5. Зависимости не добавляются без отдельного решения.
6. Юридические страницы меняются только в палитре и шрифтах; текст,
   нумерация разделов и даты редакций — ни на символ.
