# Свод решений

Свыше двухсот решений (Р-01…Р-202 и далее), принятых по проекту с
августа по сентябрь 2026 года, сведённые к существу. Полный журнал с
разбором каждого решения — `docs/DECISIONS.md` в этом репозитории; здесь
остаётся то, что нужно знать человеку, продолжающему работу над кодом.

Формат ссылки на решение по всему проекту — `Р-NN`.

---

Состав полей форм приведён к направлениям решением Р-96 — один раз и до
открытия сайта. С этого момента состав, порядок, валидация, тексты галочек
согласия и версия текста согласия заморожены: на них завязан журнал согласий
по 152-ФЗ, и изменение состава полей после появления настоящих заявок
разрывает журнал.

## Правила, действующие постоянно

1. Правится макет `design/*.dc.html`, а не сгенерированный компонент.
   Компоненты перезаписываются при каждом переносе, CI проверяет
   воспроизводимость.
2. Каждое решение записывается с разбором, а не только с результатом: через
   полгода важно, почему сделано так.
3. Принятое состояние закрепляется веткой `accepted/…` — точкой отката,
   которую не двигают и не удаляют.
4. Бэкенд не меняется правками вида: схема, миграции, `app/src/app/api/` и
   `app/src/lib/` — только отдельным решением с явной причиной.
5. Зависимости не добавляются без отдельного решения.
6. Юридические страницы правятся только по прямому указанию заказчика и
   уходят юристу на проверку; без такого указания в них меняются только
   палитра и шрифты. Ограничение снималось дважды: Р-109 и Р-114.
