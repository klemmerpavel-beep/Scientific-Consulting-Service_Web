# План: чек-листы команды и автозаполнение карточки из документов

**Статус на 12.10.2026.** План составлен по заданию владельца (промт
«Чек-листы команды и автозаполнение карточки из документов», ответы на квиз
и образцы «исходных данных на утверждение» от 12.10.2026). Работа идёт на
ветке `claude/bold-pascal-epluqc`.

Основания:
- замечание владельца 08.10.2026 и решение Р-494 — первая редакция
  чек-листов;
- задание 12.10.2026: чек-листы в кабинетах руководителя, менеджера и
  куратора, по видам работ и по процессам; шаблоны документов, из которых
  платформа сама заполняет карточку заказа;
- ответы владельца на квиз 12.10.2026: приняты улучшения У-1, У-2, У-3,
  У-4; документы из карточки (счёт, акт) отклонены; отметки чек-листов по
  видам работ сохраняются; анкета — в `.docx` и `.xlsx`; шаблоны владельца
  передаются файлами; вместо готового введения — тезисы; варианты темы — с
  выбором клиента;
- четыре образца «исходных данных на утверждение» (ВКР, магистерская
  работа, статья). В репозиторий не кладутся: тесты собирают их подобия.

Порядок работы — как у прежних планов: один пункт — один коммит со своим
решением; полная проверка группы (`typecheck`, `test`, `test:db`, `build`,
пересъёмка артбордов и прототипа, аудит облика и axe); отправка после
группы.

Обозначения состояния: **сделано** — номер решения указан; **в работе**;
**к работе**; **владелец** — нужны решение, документ или ресурс.
