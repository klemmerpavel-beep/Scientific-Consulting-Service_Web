Справочники

Справочники задают единые названия, которыми кабинет пользуется везде. Типы сопровождения — перечень видов работ: из него выбирают вид при одобрении заявки, по нему считается аналитика. Исторические написания — как тот же вид записан в книге заказов («Диссертция», «Статья ВАК»): при переносе книги такие строки сами сводятся к нужной позиции. Шаблоны этапов — готовый план работ для вида, который заводится в работу одним действием. Заливка книги — что означает цвет строки в книге заказов. Производственный календарь — переносы выходных, по которым считается срок согласования этапа. Заходить сюда нужно редко: когда появляется новый вид работ или перенос книги сообщает о несведённом написании.
