# ProDisser — сайт научного консалтинга

Публичный сайт научно-консультационного сервиса **ProDisser**
(коммерческое обозначение ООО «РУСДРОН»).

## Состояние

Проект на этапе переноса из макетов в продакшн-код. Публичного адреса пока нет.

| Этап | Содержание | Состояние |
|---|---|---|
| Э0 | Аудит и фиксация решений | выполнен |
| Э1 | Доработка дизайна | в работе |
| Э2 | Ревизия UI, UX и наполнения | |
| Э3 | Формы, кнопки и приём заявок | |
| Э4 | Продакшн-код | |
| Э5 | Размещение с доступом из России | |

Личный кабинет и административная панель начинаются после открытия сайта.

## Состав репозитория

```
design/     макеты Claude Design — источник вида и поведения
  *.dc.html      восемь поверхностей проекта
  baseline/      снимки утверждённых версий для сверки и откатов
  assets/        иконки и иллюстрации
  HANDOFF.md     описание макетов: токены, состояния, правила тона
docs/       решения и отчёты
  DECISIONS.md   источник правды по спорным вопросам
tools/      служебные скрипты аудита
  audit.mjs      прогон axe-core и замеров на трёх ширинах
  shot.mjs       рендер страниц в PNG
  slice.py       нарезка длинных снимков
```

## Как посмотреть макеты локально

Макеты — это формат среды прототипирования: шаблон с плейсхолдерами и класс
логики. Для просмотра нужен локальный сервер и рантайм среды, которого в
репозитории нет. Скрипты в `tools/` подменяют недостающие зависимости
локальными копиями и рендерят страницы в PNG:

```bash
npx http-server -p 8899 -s design
node tools/shot.mjs StartPage MainPage StudentsPage BusinessPage
node tools/audit.mjs
```

## Ключевое правило проекта

**Компания не пишет работы за клиента.** Продукт — экспертиза и сопровождение.
Любая формулировка, читаемая как «напишем за вас», — дефект. Прямое «мы не
пишем» тоже не используется: тон остаётся лояльным, роль описывается через
действия сервиса.

Полный свод правил тона — `design/HANDOFF.md`, раздел «Правила, которые нельзя
нарушать». Решения по спорным вопросам — `docs/DECISIONS.md`.
