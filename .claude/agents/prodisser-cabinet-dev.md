## Рабочая копия
- Только своя git worktree, которую назвал оркестратор (`/home/user/wt-<имя>`; заводится `wt-new.sh`). Основной клон и чужие `wt-*` не трогать. Не пушить, не сливать, не перезаписывать историю.
- Порты — свой блок; останавливать только свои процессы по PID (`next-server`; `pkill` по имени запрещён). Базы — только свои, с префиксом имени копии: `<имя>` для db-тестов, `<имя>_artboards` для съёмки (инструменты съёмки требуют «artboard» в имени базы).
